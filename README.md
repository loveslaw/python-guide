# Complete Python Guide: Beginner to Advanced

Welcome to the comprehensive Python guide! This repository is designed to take you from a complete beginner to an advanced Python programmer. It covers everything from basic syntax to advanced topics like decorators and concurrency, complete with examples and testing.

## Table of Contents

1. [01_Beginner](01_Beginner/)
   - `01_variables.py`: Data types, variables, and basic operators.
   - `02_control_flow.py`: If-else statements, loops (for, while).
   - `03_functions.py`: Defining functions, arguments, return values.
2. [02_Intermediate](02_Intermediate/)
   - `01_oop.py`: Object-Oriented Programming, classes, inheritance.
   - `02_file_handling.py`: Reading and writing files.
   - `03_exceptions.py`: Try, except, finally, and error handling.
3. [03_Advanced](03_Advanced/)
   - `01_decorators.py`: Function decorators, wrappers.
   - `02_generators.py`: Yield, iterators.
   - `03_context_managers.py`: Using `with` statements, creating custom context managers.
4. [04_Testing](04_Testing/)
   - `test_basic.py`: Examples of using `pytest` to test your code.

## How to Use

1. Clone the repository.
2. Navigate to the directory of the level you want to explore.
3. Run the Python scripts directly to see the output:
   ```bash
   python 01_Beginner/01_variables.py
   ```
4. To run tests, make sure you have `pytest` installed:
   ```bash
   pip install pytest
   pytest 04_Testing/
   ```
